## Development handoff

Start with [AGENTS.md](AGENTS.md), [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md) and [CHANGELOG.md](CHANGELOG.md). Follow the [milestone workflow](docs/WORKFLOWS.md): every completed GCPRO development milestone includes relevant documentation updates, a commit, a push and remote verification.

Current implementation record: [Homepage V2](docs/milestones/2026-10-16-homepage-v2.md). This repository documents client-specific state; it is not a WordPress backup or deployment pipeline. Shared ROBYLO source remains separate.

Authorized client-only source exceptions are documented alongside their deployment locations: [desktop process ripple](docs/milestones/2026-10-16-process-ripple.md) and [mobile viewport sequence / Custom Code590](docs/milestones/2026-10-16-mobile-sequence.md). Their presence does not establish automatic Git-to-WordPress deployment or authorize changes to shared ROBYLO.
