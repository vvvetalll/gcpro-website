# GCPRO Marketing — почати тут

**Актуальні оновлені ERP Flyer та PM Trifold:** [два PDF з оригінальними назвами, 2026-11-06](updates/2026-11-06/README.md). Використовувати ці версії замість відповідних PDF базового кіта. Джерела й перевірки — у CURRENT_RELEASE.json. Кіт від 20 жовтня збережено як історичну основу.

Це постійна база знань, дизайн-система, вихідні файли та готовий кіт GCPRO. Додано до репозиторію 2026-11-05 за запитом власника. Базовий випуск — папка, яку власник повторно надав як зразок: **GCPRO-Marketing-Kit-2026-10-20**.

## Що прочитати перед роботою

1. [AGENTS.md](AGENTS.md) — межі змін та правила для наступного асистента.
2. [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md) — кольори, шрифти, блоки, лого, фото та друк.
3. [DOCUMENT_CATALOG.md](DOCUMENT_CATALOG.md) — який файл редагувати й де його джерело.
4. [WORKFLOW.md](WORKFLOW.md) — редагування, повторний випуск і перевірки.
5. [STATUS.md](STATUS.md) — актуальний базовий випуск, виключені матеріали та незатверджені завдання.
